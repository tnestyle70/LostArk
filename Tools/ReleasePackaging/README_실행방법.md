# LostArk Release 2026-10-01 통합본 실행

1. 모든 PC에서 같은 ZIP 전체를 새 폴더에 압축 해제합니다. EXE 하나만 복사하지 마세요.
2. Drive에서 받은 최신 Resources를 준비합니다. 이 ZIP은 Resources를 포함하지 않습니다.
3. 서버 PC `192.168.0.22`에서 이번 수정이 반영된 LostArk 정본 Server를 실행하거나, 이 폴더의 `ServerHost.cmd`를 한 번 실행합니다. 같은 주소에 Server 두 개를 동시에 실행하지 마세요.
4. 각 PC에서 `LostArk.exe`를 실행하고 최신 Resources가 있는 기존 LostArk 폴더 또는 Resources 폴더를 선택합니다.

선택한 기존 폴더에서는 Resources만 읽습니다. 실행 파일·Data·DataFiles는 압축 해제한 이 폴더를 사용하며 기존 저장소에 설치하거나 덮어쓰지 않습니다. Visual Studio 없이 실행하도록 필요한 VC 런타임 DLL도 포함합니다. Windows 10/11 x64 및 .NET Framework 4.x가 필요합니다.

캐릭터 선택창은 EXE 실행마다 빈 6개 슬롯으로 시작합니다. 원하는 슬롯에 캐릭터를 만들고 플레이한 뒤 베른의 캐릭터 선택으로 돌아오면 같은 슬롯에 외형·닉네임이 표시됩니다. 각 캐릭터의 장비·아이템·실링·골드·칭호는 그 EXE 안에서 따로 유지됩니다. 다시 선택해 플레이하면 베른에서 해당 상태를 복원합니다. **EXE를 종료하면 생성한 캐릭터와 플레이 상태는 사라집니다.** 개인 JSON 저장이나 다른 EXE/PC와의 캐릭터 공유는 하지 않습니다.

F1 → Balance Test에서 Server 수치를 편집하고 `Save + Apply`를 누르면 Server가 검증·저장·게시 후
연결된 모든 플레이어에게 재시작 없이 반영합니다. Skills는 직업·슬롯·이름으로 찾고 ALT_V를 따로
고를 수 있습니다. 연결된 대미지 profile, 패턴 최대 HP 비율 피해와 공통 레이드 무력화 최대치를
구분합니다. 발탄 마력구·쿠크 무력화는 HP 피해와 별도로 원래 피해의 1/1000을 무력화에 적용하며,
회오리 수류탄은 공통 최대치의 1/3을 적용합니다.
다른 플레이어가 먼저 저장하면 현재 draft는 보존되고 Server 값을 다시 읽어야 합니다.
플레이 중 수치를 조정하고 `SAVED AND APPLIED`를 확인한 뒤, 처음부터 다시 시험하려면 게임 안의
관문/레이드 재시작을 사용합니다(필요한 파티 승인 포함). EXE나 Server 프로세스를 껐다 켤 필요는 없습니다.
Server가 저장하는 Data·bootstrap·numeric receipt는 같은 폴더에 함께 보존하세요. 실행기는 이 영수증과
파일 hash를 검사하므로 일부 저장 파일만 이전 ZIP 파일로 덮어쓰지 마세요.

모든 Client는 같은 서버 `192.168.0.22:7777`로 접속합니다. 서버 PC에서도 Client를 실행할 수 있고 한 PC에서 여러 Client를 실행할 수도 있습니다. 다른 PC는 Server를 실행하지 않습니다. 이번 통합본은 protocol 132이므로 이전 Client 또는 Server와 섞어 실행하지 마세요.

이번 통합본의 우선 확인 항목은 다음과 같습니다.

- 이동: 40~60 FPS 구간에서 이동 중 반복 우클릭, 방향 전환, 클릭 후 즉시 버튼 해제와 스킬 사용을 확인합니다. 일반 이동 클릭은 Debug와 Release 모두 같은 프레임의 CPU 표면 검색으로 처리합니다. F1 테스트 허브는 사용할 수 있으며 F7 프로파일러와 화면 FPS 표시는 이 Release에서 비활성화되어 있습니다.
- 콜로세움: 베른에서 대기하면 10초와 현재 인원 N/4가 표시됩니다. 10초 뒤 1~4명을 입장 순서로 양 팀에 배정하며 로딩 준비는 인간 수를 기준으로 1/1·2/2·3/3·4/4로 표시합니다. 각 팀 앞의 용병 다섯 후보 중 직접 고용해 양 팀을 각각 4명으로 맞추면 10초 입장 안내, 도열, 경기 카운트다운과 전투가 이어집니다. 3인 입장은 왼쪽 인간2명+용병2명, 오른쪽 인간1명+용병3명입니다. 인간1명으로 입장하면 상대 팀 용병4명만 자동 배정되며, 본인 팀에 용병3명을 직접 고용하면 전투가 시작됩니다.2~4인 입장은 양 팀이 필요한 용병을 직접 고용합니다. 입장 도열은 서버 참가자, 승리 연출은 승리 팀의 실제 참가자 최대4명을 사용합니다.
- 카드 미로: Release에서도 혼자 상자를 부순 뒤 망원경에 Q를 사용해 시작할 수 있습니다. 다인 플레이는 기존 관찰자·사냥꾼 역할을 유지합니다. 해당 문양의 카드 병정을 처치한 뒤 탈출 문양이 유효한 랜덤 통로에 생성되는지 확인합니다.
- 쿠크 1관문: 첫 연출 음원이 프레임 지연 중 반복 재시작하지 않는지 확인합니다. 인형의 불 방향과 광기 판정, 즉사 칼날의 절반 속도도 포함합니다.
- 장비: 내구도 감소와 수리 NPC 창의 수리 결과를 확인합니다.
- 워터팡: 마하라카 진입 로딩에서 AI 외형과 물총을 미리 준비합니다. 경기 대기 중 첫 등장 정지, `Waterpang AI 1~20` 닉네임과 NPC 8종의 물총 부착을 확인합니다.
- 가이드: 베른 스퀘어홀·출항 준비로 같은 맵의 항구에 이동하면 기존 가이드가 따라오는지 확인합니다. 실제 승선·레이드 출발 때는 베른에 대기합니다.

Release에서도 서버 월드에 입장한 뒤 `F1 → Battle Items → Give all four (10 each)`로
파괴폭탄·회오리 수류탄·성스러운 부적·시간정지물약을 각 10개 지급받을 수 있습니다.
`I`로 인벤토리를 열어 HUD의 1~4번 아이템 슬롯으로 드래그하고, F1을 닫은 뒤 해당 숫자키로
사용합니다. 폭탄은 바닥을, 성스러운 부적은 같은 파티의 다른 플레이어를 가리킵니다.
시간정지는 자신을 3초간 보호합니다. 수량·사용 가능 상태·사거리·쿨타임은 서버가 검사합니다.

실행하지 않고 파일과 경로를 검사하려면:

```powershell
.\LostArk.exe --check "C:\Users\user\Desktop\LostArk" .\preflight.json
```

발탄은 4인 입장·컷씬·체력별 패턴·부활과 유령 처치·클리어, 쿠크는 입장·1~3관문·마리오·빙고·최종 연출과 MVP를 사용자 화면에서 확인합니다. 구조화된 서버 검사와 ZIP 검증은 네 Client의 실제 화면·음향·LAN 품질 판정을 대신하지 않습니다.

이번 발탄 수정은 아래 장면을 네 PC에서 확인합니다.

- 집결 구역에서 10초가 지나면 추가 확인창 없이 발탄 입장 컷씬 또는 쿠크 3관문으로 이동합니다. 발탄 컷씬 뒤에는 일반 휠윈드 한 번으로 시작합니다.
- 버러지를 놓치거나 잡혀도 재시도 동작이 이어지고, 실제 카운터 성공 후 다음 패턴으로 넘어갑니다.
- 버러지들 왼손 내려찍기 뒤 플레이어가 찍은 손 부근의 이동 가능한 지면에 내려오는지 확인합니다. 발탄 등 뒤나 맵 밖으로 되돌아가면 안 됩니다.
- 마력구 패턴에서 실제 무력화 게이지가 F1에 저장한 Valtan Stagger 위치·크기로 표시되고 타격에 따라 변하는지 확인합니다.
- 4연속 공격으로 공중에 뜬 상태에서 속박에 진입해도 연결이 유지되고, 해당 플레이어에게 보라색 속박 문구가 한 번 표시되는지 확인합니다.
- 갑옷 파괴 창에서 파괴 폭탄으로만 갑옷이 제거되고 파편이 재생됩니다. 부위 파괴 뒤 네 방향 돌은 생성하지 않습니다. 갑옷이 모두 벗겨진 뒤에는 돌진·폭탄을 반복해도 파괴 표시와 파편이 다시 나오지 않습니다.
- 발악 포탈은 앞에 열리고 발탄이 돌진해 들어간 뒤 중앙으로 돌아옵니다. 플레이어 위치의 붉은 원형 예고는 숨기고 폭발은 유지합니다.

가디언 나이트는 용 문양이 양쪽 뿔과 같은 방향으로 차오른 뒤 완성 문양으로 이어지는지, 리벤지 스피어 검격이 반시계 90도 방향과 원본 찌르기 클립 길이로 재생되는지 확인합니다.

실패한 Client PC와 서버 PC에서 각각 다음 명령으로 진단 기록을 수집할 수 있습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Collect-RuntimeDiagnostics.ps1 -RuntimeRoot .
```
