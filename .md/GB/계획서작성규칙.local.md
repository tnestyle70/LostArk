# LostArk 활성 개인 계획서 규칙

계획서, 구현 가이드, G별 코드 설명을 작성하기 전에
`.md/GB/계획서하네스규칙.local.md`를 처음부터 끝까지 읽고 가장 먼저 따른다.
그 다음 `.md/GB/local.md`와 `.md/GB/계획서작성규칙.md`를 처음부터 끝까지 읽는다.

merge, pull, rebase, 충돌 해결 이후 계획을 재개할 때는
`.md/GB/gotchas.md`와 `.md/GB/gotchas.local.md`도 먼저 읽는다.
G별 직접 구현 설명의 Effect Tool G1 예시는 `.md/local.계획서예시.md`를 참고한다.

이전 설명 원문은 `.md/GB/코드작성규칙.local.md`에 보존되어 있으며 수정본의 예시 근거로만 사용한다.

핵심 분리는 다음과 같다.

```text
PLAN        = 생략 없는 실제 반영 코드 정본
대화 세션  = G별 파일 존재 이유, H 계약, struct/변수 의미, CPP 함수 한 줄 책임과 흐름
RESULT      = 실제 구현 상태와 실행한 검증 증거
```
