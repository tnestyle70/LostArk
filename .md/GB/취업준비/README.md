이 `.md/GB/취업준비/` 경로는 요청대로 Git ignore에 추가하지 않았다. 이곳에는 이동 안내만 두며 학습 문서와 답변 원문은 Interview에서만 수정한다. 다른 PC의 로컬 폴더 배치가 다르면 위 GitHub 저장소를 사용한다.

LostArk 루트의 `취업준비/`는 `/취업준비/` 규칙으로 Git에서 제외한다. 게임 소스·런타임·렌더 설정에는 변경이 없다. Interview의 commit/push와 노트북에서 실제 수신했는지는 해당 저장소의 Git 상태로 따로 확인한다.
