### 오버레이가 안 보인 원인
`UI_Sprite.cpp:62`: UI 라우터가 시네마틱 억제 상태(`Is_CinematicSuppressed`)일 때 `Set_CinematicOverlay(true)`가 아닌 스프라이트는 그리지 않는다. 컷신 중에는 MainApp이 HUD를 숨기려고 억제를 켜므로, 컷신이 만든 레터박스·페이드 판·VS 7장이 전부 가려졌다. Kouku/Valtan 컷신 UI는 슬롯마다 `Set_SlotCinematicOverlay`를 켠다. 이번에 같은 방식으로 컷신 레이아웃의 모든 슬롯에 켰다.

## 2. 원본 매티니 재조사 (`interpdata_3`, 전 트랙 확인)
그룹 14개와 트랙을 전부 덤프했다.

| 원본 트랙 | 사용 여부 |

| 디렉터: 페이드 4키, 이벤트 8키(VS·이름 줄 등장/퇴장) | 이미 사용 |

| c1 카메라 + 붐(`interpgroup_11`, 2키) | 이미 사용 |
| 배우 6명 이동/회전 + `idle_normal_1` 루프(3000ms부터) | 위치·방향 사용, 애니메이션은 캐릭터의 실제 대기 |

| `interpgroup_9` 세 번째 카메라(5042ms, pitch -23) | 디렉터 컷 목록에 없음 → 사용되지 않음 |
| `interpgroup_1` (상대 이동, 값 0) | 영향 없음 |

즉 트랙이 빠진 것은 없다. 틀린 것은 FOV 해석이다.

### FOV 재해석
- 매티니의 75는 16:9 화면 기준 수평각이다. 원본 화면은 2.35:1로 더 넓게 잘리는데, 넓은 쪽은 **수직각을 유지**하는 방식이라 수평각은 `2·atan(tan(37.5°)/(16/9)·2.35) = 90.8°`가 된다.
- 근거: 영상 실측. 도열 샷에서 6명의 발 위치와 슬롯 좌표(x/깊이)의 비로 계산한 화면 기울기 0.455(수평각 약 96도, 75도면 0.65). 항공 샷에서 6명 폭 0.115와 팔각형 폭 약 0.5를 navgrid(폭 27.5m)와 카메라 위치로 계산하면 84~86도. 두 값의 가운데가 90.8도다. 수평 75도라면 두 샷 모두 훨씬 좁게 나온다.
- 한계: 카메라 위치가 매티니에서 온 값이라, 위 실측도 그 좌표에 의존한다. 오차 약 ±6도.
- 조치: `build_colosseum_intro_cutscene.py`에 도출식을 넣고 `Data/Camera/ColosseumIntro.cutscene.json`을 그 스크립트로 다시 생성했다. 바뀐 것은 `fovXDegrees` 75 → 90.814 한 줄뿐이다(나머지 값과 `IntroCutscene_Layout.json`은 바이트 동일 확인).

## 4. F1에서 재생하는 방법
1. Debug 로비 `Colosseum` 버튼(또는 베른 성 NPC)으로 콜로세움에 입장한다.
2. **F1 → 스크롤해서 `Colosseum Intro Cutscene` 섹션**(`Dragon` 컨트롤 아래, `Character Select Movie` 위쪽 영역). 콜로세움 레벨에서만 나타난다.
3. 버튼:
   - `Play`/`Restart`: 처음부터 재생. **누를 때마다 `Data/Camera/ColosseumIntro.cutscene.json`을 다시 읽으므로**, 카메라·FOV·타이밍을 JSON에서 고치고 Play만 다시 누르면 재빌드 없이 확인된다. 입장 때 문서가 거절됐어도 여기서 복구된다.
   - `Pause`/`Resume`: 현재 프레임에서 정지(카메라·오버레이는 유지).
   - `Stop`: 즉시 종료하고 원래 화면·캐릭터 위치로 복귀.
   - `Time (s)` 슬라이더: 재생 중 원하는 시각으로 이동.
4. 표시: 상태(대기/재생/일시정지/종료 fade), 현재 FOV, 도열에 선 캐릭터 수, 실패 사유.
5. 재생 중에는 입력과 HUD가 막힌다(원래 컷신과 동일). F1 창의 ImGui는 그대로 조작된다.
- 방에 연결된 플레이어만 6칸 슬롯에 서므로 혼자 재생하면 1명만 선다. 6명 구도는 실제 접속 인원이 있어야 확인된다(더미 소환은 만들지 않음).

## 5. 이번에 고치지 않은 차이
- **밝기·색**: 우리 콜로세움 영상은 어둡고 바닥이 청록빛이다. Colosseum Area에는 `maplights`도 렌더링 profile도 없다(`RenderingProfiles.json`에 항목 없음, MapCatalog에 lights 선언 없음). 조명·후처리는 팀장 정본이라 임의로 추가하지 않았다. 원본 화면과 같은 밝기가 되려면 별도로 콜로세움용 scene profile/map light를 정해야 한다.
- 라벨의 파란 글로우 띠와 `<등급>` 표기.
- 원본 배우 아바타의 개별 대기 동작.
- DOF(값이 사실상 꺼진 상태).
