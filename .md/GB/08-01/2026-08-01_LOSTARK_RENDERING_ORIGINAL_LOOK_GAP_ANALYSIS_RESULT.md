## 1. 기준점 — 원작이 실제로 쓰는 것

원작은 UE3(빌드 12097) 대개조 엔진이다 (DX9 출시 → 2021-12 DX11 추가 → 이후 DX11 일원화 → 2025-12 DLSS/FSR). 렌더링 내부는 비공개지만 인게임 그래픽 옵션으로 확인되는 후처리 체인이 목표 스펙이다.

| 확인된 원작 요소 | 근거 |
|---|---|
| 블룸, 플레어(라이트 섀프트), 왜곡(디스토션), 모션 블러, DOF, 간접 그림자(SSAO류), 안티앨리어싱, 파티클 품질 옵션 | 인게임 그래픽 설정 항목 |
| 스킬 카메라 셰이크(옵션으로 일부만 제어), 휠 줌, 고정 쿼터뷰 | 공식 Q&A·포럼 |
| 재련 단계별 무기 글로우(+10부터, 15/20/25 구간 강화), 무기 이펙트 도감 | 공식 게임 가이드 |
| 발탄: 붉은 텔레그래프 장판, 지형 파괴·낙사, 고스트 페이즈(푸른 톤 전환), 갑옷 파츠 파괴 | 공식 보도자료·공략 문서 |
| 지역·페이즈별 화면 톤 전환(컬러 그레이딩 계층) | 관찰 기반 추정 |
| 캐릭터 림라이트/외곽선 옵션, 스타일라이즈드 스페큘러 | 옵션 목록 + 관찰 추정 |

개발 시기(2011~2014)상 원작은 **비-PBR 핸드튜닝 스타일라이즈드 라이팅**으로 추정된다. 즉 "원작 느낌"의 본질은 물리 정확도가 아니라 **후처리 체인 + 조명 무드 + 전투 연출 밀도**다. 현 엔진의 Lambert+Phong 디퍼드를 PBR로 갈아엎을 필요는 없다.

## 4. 권장 진행 순서 (P6 진입 시)

```text
1단계  ① sRGB → ② HDR+톤맵 → ③ 블룸 → ④ FXAA → ⑤ LUT   (풀스크린 체인 한 설계로)
2단계  ⑥ 라이트 데이터화/포인트 → ⑦ 그림자 배선/PCF → ⑧ 포그+반구 앰비언트
3단계  ⑩ 스킨드 5채널 → ⑪ 림라이트 → ⑫ 히트 플래시
4단계  ⑬ 텔레그래프 → ⑭ 이펙트 승격 → ⑮ 카메라 → ⑯ 히트스톱 → ⑰ 크로스페이드
5단계  ⑱~㉑
```

- 1~2단계만으로 스크린샷 체감이 달라진다(색 공간 + 블룸 + 그림자 + 지역광).
- "발탄다움"은 4단계에서 완성된다. ⑬⑭⑮는 P5 서버 Encounter 이벤트 계약(TelegraphCue/EffectCue/CameraCue)의 소비자이므로 P5와 계약을 맞춰 설계한다.
- 각 항목은 북극성 §20 원칙대로 **개별 profiler gate**를 통과한 것만 켠다.
