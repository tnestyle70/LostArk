### 4.3 불변식

- 세 view는 `HUD_KOUKU_GIMMICK_STATE.isValid`가 false이거나 Kakul 레벨이 아니면 모든 슬롯을 숨긴다. 값·판정·쿨다운을 UI가 만들지 않는다.
- 광기 게이지 슬롯 위치는 매 프레임 `Set_SlotPosition`으로만 바뀌고 authored rect는 상대 오프셋 정본이다. 투영 실패(화면 밖·카메라 뒤)면 숨긴다.
- 댄스 결과 연출은 결과 tick이 바뀔 때 한 번만 `Restart_Animation`/alpha 타임라인을 시작한다.
- JSON 로드는 `CUILayoutRuntime` 기존 `parse -> validate -> stage -> commit`을 따르고 실패 시 해당 view만 비활성.
