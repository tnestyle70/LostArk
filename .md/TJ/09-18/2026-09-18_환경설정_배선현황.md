# 환경설정 창 — 행별 배선 현황 (2026-09-18)

브랜치 `feature/system-options`. 창은 `EFTable_SystemOption`의 원작 행 표(`Data/UI/SystemOption/SystemOptionRows.json`,
비디오·오디오·접근성·게임 플레이 4계열 279행)를 전부 놓았고, 그중 엔진이 실제로 소비하는 행만 값이 살아 있다.
나머지 행은 원작 모양 그대로 눌리고 값도 바뀌지만 아무것도 읽지 않는다. 설정은 이번 실행 안에서만 유지되고
파일로 저장하지 않는다(다음 실행은 원작 기본값).

값을 읽는 쪽은 전부 `CUserSettings`(`Client/Public/UserSettingsDocument.h`)를 거친다. 행 id는 그 헤더의
`SystemOptionRowId` 상수와 같다.

## 1. 구현한 것

### 1.2 창 구성

- 원작 상대 배치 규칙을 그대로 해석해 279행을 놓는다: 각 행은 부착 대상 행 기준으로 `direction 3`(아래) / `2`(오른쪽) + 여백으로 자리를 잡고,
  컨트롤 종류별 높이(콤보 34, 슬라이더 24, 체크 31, 스피너 28, 버튼 30, 그룹 제목 24, 구분선 5)를 쓴다. 원작 스크린샷과 템플릿 매칭으로 수치 대조.
- 탭 트리: 비디오·오디오·접근성은 단일 탭, 게임 플레이는 부모(펼침/접힘 화살표) + 전투 표시/조작/표시/네임태그 4자식. 커뮤니티·단축키·게임패드는 원작처럼 접힌 채 보이기만 한다.
- 컨트롤 전부: 콤보(드롭리스트, 원작 배경판 포함, 최대 11항목), 슬라이더(드래그·값 표시·스피커 아이콘), 체크박스, 스피너(±10), 라디오 목록(5열), 색상 프레임, 그룹 제목(★), 소제목, 구분선, 행 hover 하이라이트.
- 오디오 행은 원작대로 한 줄(라벨 + 스피커 + 슬라이더 + % + 켜기 체크)로 데이터가 놓는다.
- 스크롤: 휠·썸 드래그·화살표. 화면별 스크롤 위치 기억. pane 밖은 스프라이트 UV 클리핑 + 텍스트 clip-in.
- 버튼: 전체초기화 / 초기화 / 적용 / 확인 / 취소 / X. 편집은 즉시 반영(들리고 보임), 취소·X·Esc는 창 열 때 스냅샷으로 복원, 적용은 변경 있을 때만 활성.
- 제목 띠 드래그로 창 이동(위젯도 같은 프레임에 따라감), Esc 열기/닫기(다른 창 없을 때만 열림, 열린 드롭리스트 먼저 닫힘).
- 원작이 회색 처리하는 행(업스케일링 모드, 모코코 커서의 외곽선, Enabled=0)은 회색 + 조작 불가. 해상도/화면 모드는 표시 고정.
- 설정은 프로세스 안에서만 유지(`CUserSettings`), 파일 저장 없음.

### 1.4 같이 고친 짜잘한 것

- 캐릭터 선택 우하단 몬스터 소환/보스 소환/되돌리기 라벨이 한 배율을 공유(몬스터 소환만 작던 것).
- 커스터마이징 머리 탭의 머리 색상 / 머리 윤기 캡션 겹침.

## 2. 비용 적게 넣을 수 있는 것 (아직 안 넣음)

| 행 | 비용 | 방법 |
|---|---|---|
| 왜곡 효과 (`checkbox_filter_effect_distortion`) | 작음 (~15줄) | 후처리 패스의 왜곡 샘플이 한 곳(`Shader_Deferred.hlsl` 1187행 부근). 플래그 하나 추가해 오프셋을 0으로 |
| 그림자 품질 (`combobox_shadowquality`) | 작음 (~15줄) | 렌더러엔 해상도 단계가 없고 켜기/강도뿐. 최상·상 = 그대로, 중 = 강도 절반, 하 = 끄기로 근사. 원작 1:1은 아님 |
| 숫자 축약 (`checkbox_battle_font_short`) | 작음 | 피해 숫자 표기를 줄여서 표시. 원작 형식(`1.2만` / `12.3K`) 확인이 먼저 |

## 3. 가능하지만 비용이 큰 것 (안 함)

| 행 | 왜 큰가 |
|---|---|
| 해상도 / 화면 모드 (전체·창·전체창) | 스왑체인·렌더타깃 전부 재생성 경로가 없다. 창 모드 1280x720 고정 |
