## 2. 관문 진행 (Server 권위, protocol 91)

### 원작 자료
- 좌상단 위젯 = `EFUI_EPICGATECOMMANDERPROCESS` `EpicGateCommanderProgressFrame`(sprite 172): bg 302×265(축약 프레임 2),
  `gateIcon0..2` (59,74)/(121,74)/(183,74) 59×65, 상태 프레임 `check`(체크 붙은 문장)·`active`(파란 글로우)·`inactive`(파란 문),
  `dungeonName` 18px (11,7) 중앙, 두 번째 줄 `[노말]`. 텍스처는 umodel로 `epicgatecommanderprocess_i5a/i52/i60`.
  호스트가 놓는 화면 위치는 문서에 없어 기준 (8,12)에 2/3 배율로 뒀다.
- 흐름 문자열(GameMsg `sys.commander.*`): `progress_vote` "던전 진행", `progress_vote_dialog_desc`
  "던전을 계속 진행하시겠습니까?", `_desc_1` "{0}님이 던전 진행을 신청하였습니다…", `progress_vote_fail_dialog_desc`,
  `stop_dungeon_progress` "중단하기". 관문 보상 창(`ResultFrame`)은 보상 데이터가 없어 이번엔 생략.

### Shared
- `C2S_GATE_PROGRESS_PROPOSE {seq, world}`, `C2S_GATE_PROGRESS_RESPOND {seq, proposalId, accept}`,
  `S2C_GATE_PROGRESS_STATE {world, gateCount, currentGate(1-based), clearedMask, proposalId, proposerNetId, accepted, total, closed, result}`.
  `NETWORK_PROTOCOL_VERSION` 90 → 91. Server/Client 함께 빌드·재시작 필요.

### Server (`GameRoom_GateProgress.cpp`)
- 관문 표(쿠크 3관문: placement id + 플레이어 위치, F1 표와 같은 값)를 Server가 소유.
- `Notify_GateBossDeath`: 주 보스 DEAD despawn 때 같은 관문의 다른 보스가 없으면 클리어 비트 세우고 broadcast
  (2관문은 대형 세이튼·쿠크 중 마지막).
- `Note_GatePlacementRaised`: 관문 placement가 올라오면(F1 버튼 포함) 그 관문을 current로.
- 투표: 파티 raid entry 투표와 같은 규칙(리더=roster front, 솔로는 즉시 확정, 30초 timeout, 거절 즉시 실패).
- `Advance_Gate`: `Reset_CardMaze` → `Despawn_KoukuSaydonArenaDebugEntities` → 다음 관문 placement spawn
  (`Build_WorldEntity`, `Apply_KoukuGateEntryCard`, broadcast) → 모든 플레이어를 기존 navigation 검증
  (`Validate_DebugTeleportDestination`)으로 이동. 죽었거나 속박된 플레이어는 자리에 남는다. Release에서도 동작.

### Client
- `CRaidGateProgressView`: 위젯(`Data/UI/RaidGateProgress/RaidGateProgress_Layout.json`, 아트 4장) + 진행/투표 프롬프트
  (`RaidGateVote_Layout.json`, 파티 초대 모달의 패널·버튼 재사용) + 상단 알림.
- 쿠크 Level: `S2C_GATE_PROGRESS_STATE`로 클리어 문양 트리거, 시상식 닫힌 뒤 리더에게 "던전 진행/중단하기",
  파티원에게 "{이름}님이 … 수락/거절", 실패 알림, Server가 올린 관문의 표현(`Apply_ServerGate`: HUD focus·
  combat analysis 초기화, Debug에서는 관문 오브젝트·조명·audition 대상까지).
- 발탄 Level: 위젯만(1관문, 클리어 시 체크).
