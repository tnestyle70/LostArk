# 원작 전체 지도(M키)·확장 미니맵 전수조사 (2026-09-17)

팀장 요청: 우상단 미니맵을 확장해 원작처럼 M 키로 전체 지도를 여는 기능. 이 문서는 구현 전 조사 결과와 추출 데이터 위치만 담는다. 코드 변경 없음.

## 1. 결론

원작은 지도가 세 겹이다. 어느 것을 "M키 전체맵"으로 삼을지 먼저 정해야 한다.

| 겹 | 원작 키 설정 항목(`GameMsg`) | gfx | 지도 그림의 출처 |
|---|---|---|---|
| 미니맵 | `sys.preferences.hotkey_mini_map` 미니맵 | `EFUI_MAP/minimap.gfx` (`MinimapFrame` 326×264, 우상단) | host 렌더타깃(`minimapRTComponent`) — 지역 타일 텍스처 |
| 확장 미니맵 | `hotkey_expansion_mini_map` 확장 미니맵 | `EFUI_MAP/minimapex.gfx` (`MiniMapExFrame` 948×948, 화면 중앙 오버레이) | host 렌더타깃(`MinimapExRenderTarget`) — 같은 타일, 플레이어 중심 |
| 월드맵 | `hotkey_world_map` 월드맵 | `EFUI_WORLDMAP/worldmap2.gfx` (`worldMapWnd2` 창, 캔버스 1440×768) | host 렌더타깃(`WorldMap2RenderTarget`) + 존별 `_Full` 개요 텍스처 + 대륙/세계 단계 |

- 원작 기본 키는 데이터 파일에 없다(키 기본값은 exe 안). 항목 이름으로 볼 때 "M = 월드맵, Tab = 확장 미니맵"이 원작 기본값이며, 사용자가 말한 "M 키 전체맵"은 월드맵 창의 **존(지역) 단계**다.
- 어느 겹이든 gfx는 틀·마스크·아이콘만 갖고 **지도 그림은 host가 그린다**. 우리 구현도 지금 `CMinimapView`가 쓰는 "한 스프라이트에 UV 창(`Set_SlotUVWindow`)으로 지역 이미지를 스크롤·줌"하는 방식을 그대로 키우면 된다. 새 렌더타깃은 필요 없다.
- 존 단계 전체 지도 그림은 원작에 완성본이 있다: `EFMINIMAP_<대륙>` 패키지의 `<Level>_<vol>_Full` 텍스처(베른성 야외 768×768). 우리가 이미 쓰는 타일 스티치본(`UI/Minimap/Maps/BernCastle.png` 1280×1280)과 같은 내용이며, 볼륨별 개요 이미지가 따로 있어 실내(베른성 실내 11개 볼륨)도 바로 쓸 수 있다.

추천 구현 범위(1차): M 키 → 월드맵 창의 존 단계만. 창 틀(`worldmap2` 아트) + 존 `_Full` 이미지(줌·드래그) + 플레이어/파티/보스 마커(현재 미니맵 마커 재사용) + `MapString` 지역 이름 라벨(베른성 20개). 대륙/세계 단계·범례·메모·검색은 후속.

## 5. 구현 제안 (팀장 참고)

1. 데이터: `Data/UI/Minimap/MinimapAreas.json`에 존별 `fullImage`(볼륨 0)와 실내 볼륨 목록(`_Full` + cm 박스)을 추가. 파서 JSON을 그대로 옮기면 된다.
2. 창: `Data/UI/WorldMap/WorldMap_Layout.json`(1280×720 기준 창 원점 (153.3, 68.7), 캔버스 960×512) — 틀은 `worldmap2_i1a`의 1448×776 판, 배경은 `worldmap2_i8`의 1440×768 영역, 지도 슬롯은 캔버스 안 한 스프라이트 + UV 창(현재 `CMinimapView`와 같은 방식, 초기 줌은 `MapFactor.WorldmapScaleFactor` 1.4), 하단 버튼 3개(전체 월드 보기·현재 위치 보기·플레이어 표시)와 닫기 X.
3. 마커: 미니맵 마커 스냅샷(`CClientReplication::MINIMAP_MARKER_SNAPSHOT`) 재사용, 크기는 원작 화살표 45×60(948 캔버스 기준).
4. 라벨: `MapString` 20개를 `$YG760` 14px로 캔버스 px에 배치(보정 뒤).
5. 입력: `CUIInputRouter`로 M 토글, 드래그·휠 줌은 칭호 창과 같은 `Get_MouseWheelNotches` 경로. 열려 있는 동안 gameplay 마우스 차단은 기존 창들과 동일.
6. Tab 확장 미니맵은 같은 스프라이트를 632×632(948×2/3) 중앙 오버레이로 그리면 되므로 2차로.
