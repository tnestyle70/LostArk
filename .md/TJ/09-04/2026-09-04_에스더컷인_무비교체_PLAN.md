# 2026-09-04 에스더 컷인 무비 교체 PLAN

원작 `Esther_Skill_*` Bink 무비(복호·특정 과정은 `../09-03/2026-09-03_캐릭터선택창_PLAN.md`
"2026-09-04 진행 기록 2")를 DXT5 flipbook으로 굽고, `CEstherCutinPresentationService`의
NPC 모델 카메라 렌더(ScreenCutin pass + 튜닝 카메라)를 **완전히 제거**한 뒤 그 자리에 풀스크린
flipbook 재생을 넣는다. 사용자 결정(2026-09-04): 단독 컷인 5종, 1280×720 DXT5 30fps 전 프레임,
기존 방식 완전 제거.

## 원작 실측 (배치 근거)

- `Table_MovieData.loa` `EstherSkill.<Name>` → 무비 `Esther_Skill_<Name>` → RT `EpicSKillAniTexture`
  **1920×1080**.
- `EFUI_EPICSKILLANI.upk` / `epicSkillAni.gfx`: 스테이지 1920×1080, 스프라이트 1개가
  `EpicSKillAniTexture`를 (0,0) 항등 행렬로 배치. `EpicSKillAniFrameMc` ARKFrame:
  `pivotType=bottomRight, positionU=1, positionV=1, fixedWidth=1920, fixedHeight=-1,
  enableScale=false, sortingLayer=3_topmostHUD`, 히트테스트 비활성.
- 결론: 별도 배치 데이터 없음. 무비 자체가 화면 규격이고 캐릭터가 우하단에 그려져 있으며, UI는
  그 한 장을 우하단 모서리 기준으로 붙인다. 후반 전면 베기가 화면 전체를 덮으므로(alpha bbox
  1920×1080) 우리 1280×720 기준 해상도에서는 (0,0,1280,720) 풀스크린 슬롯 하나가 동일 배치다.

## 산출물

1. **텍스처** (물리 폴더, Git 비추적) `Client/Bin/Resources/UI/EstherCutin/<Name>/<Name>_NNN.dds`
   — `Tools/MoviePipeline/make_esther_cutin_dds.py`가 bk2 → bink2w64.dll 디코드 → 프리멀티플라이
   LANCZOS 1280×720 → DXT5. Silian 130 / Waye 111 / Bahunturr 107 / Inanna 111 / Ninave 116장,
   합계 575장 505.6MB. 투명 프레임도 타이밍 보존을 위해 유지. `UI/EstherCutin/cutin_empty.png`
   (4×4 투명)은 슬롯의 authored 레이어용.
2. **NPC 카탈로그** `Data/Actors/NpcCatalog.json` — 에스더 3종(NPC_59030 실리안, NPC_58700 웨이,
   NPC_59060 바훈투르)의 `cutinWindow`(모델 렌더 가시 구간; 소비자 제거로 고아) →
   `cutinMovie: { framePrefix, frameCount, fps }`. 이난나/니나브는 NPC 엔트리가 없어 데이터만 굽고
   연결하지 않는다. `Publish-WorldGameplay.ps1`은 archetypeId만 읽으므로 영향 없음.
3. **파서** `Client/Public+Private/ActorCatalog.*` — `NPC_ACTOR_ENTRY::cutinStartMs/cutinEndMs` →
   `NPC_CUTIN_MOVIE cutinMovie`(framePrefix Resources ID, frameCount>0, fps>0, `actionClips` 필수).
4. **레이아웃 JSON** (신규) `Data/UI/Esther/EstherCutin.json` — 슬롯 `Esther_Cutin` (0,0,1280,720),
   레이어 `UI/EstherCutin/cutin_empty.png`. Client.vcxproj(.filters) `96.DataFiles\UI` None 등록.
   HUDLayoutTool 문서 테이블에는 넣지 않는다 — 슬롯이 풀스크린 고정이라 저작할 것이 없고,
   툴 palette가 폴더를 재귀 스캔하며 모든 이미지를 즉시 로드하므로 575장 DDS를 팔레트에 올리면
   안 된다. 같은 이유로 프레임 폴더를 `UI/Esther/` 아래가 아니라 `UI/EstherCutin/`에 둔다
   (기존 `Esther UI` 탭 palette 오염 방지).
5. **서비스 재작성** `EstherCutinPresentationService.*` — static 클래스 → `CMainApp`이 소유하는
   인스턴스. ctor가 `CUILayoutRuntime(LEVEL::STATIC, Layer_UI, EstherCutin.json)`을 만들고 숨김.
   `Update(fTimeDelta)`: `HUD_ESTHER_CUTIN_REQUEST.iGeneration` 변화 → NPC 엔트리 `cutinMovie` →
   `<prefix>_%03d.dds` 목록으로 `Set_SlotAnimation("Esther_Cutin", frames, fps, false)` +
   `Set_SlotVisible(true)`, 시작 Level 기억. 매 프레임 `view.Update`, `frameCount/fps` 경과 또는
   Level 변경 시 종료(숨김 + 빈 frames). 모델/셰이더/카메라/튜닝/`cutinWindow` 로직 전부 삭제.
   `#ifdef _DEBUG Debug_Preview(archetypeId)`만 유지(요청 재발행).
6. **ViewModel** `CombatHUDViewModel.h` — `HUD_ESTHER_CUTIN_REQUEST.Clips` 제거,
   `Apply_EstherCutinAction(archetypeId)`로 축소. 호출자 `ClientReplication.cpp` 2곳 갱신.
7. **MainApp** — `m_pEstherCutinService` 생성(m_pEstherUIView 직후, 게이지 UI 위·이후 문서 아래),
   `Update()`에서 `Update_EstherGauge()` 다음 `Update(fTimeDelta)`; post-EndFrame `Render` 호출 제거;
   F1 "Esther Cutin (Debug)" 패널은 튜닝 드래그 제거하고 미리보기 버튼 3개만 유지.
   `Prototype_Component_Shader_VtxEstherNpc`는 월드 에스더 NPC·RaidBossShowcase가 계속 쓰므로 유지.

8. **Server 테스트 편의(사용자 지시 2026-09-04)** `Server/Public+Private/EstherSkillSystem.*` —
   `Initialize`가 `VALTAN_ARENA`뿐 아니라 `CHARACTER_SELECT_ARENA`에서도 게이지를 활성화한다.
   Client의 에스더 UI는 `Update_EstherGauge`의 raid-arena 게이트로 Character Select에서 계속 숨겨지고,
   Ctrl+Z/X/C → `C2S_USE_ESTHER_SKILL` → 5초 충전 후 summon → `esther.strike` NPC 스폰 → 컷인만 동작한다.
   `ServerGameplayContractTests.cpp`의 gauge 소유 계약에 Character Select room 활성 assertion 추가.

9. **컷인 타이밍(원작 데이터)** `EFTable_EpicSkill.db`(`SourceData/LPK/data2/.../TableData/`)
   `SkillDecoDelayTime1~3` = 캐스터의 에스더 호출 액션 시작 기준 컷인 지연: 실리안 0 / 웨이 2800 /
   바훈투르 2000 ms (니나브 0, 이난나 0). 에스더 NPC 액션 XML(`NP_LRSA_00.loa` 등)에는 컷인 notify가
   없다 — 원작은 NPC 애니메이션 프레임이 아니라 캐스터 타이밍으로 튼다. 우리 서버는 키 입력 후 1000ms에
   소환(strike 클립 시작)하므로 `cutinMovie.delayMs` = 스폰 기준 지연 = max(0, Deco − 1000):
   실리안 0 / 웨이 1800 / 바훈투르 1000. 서비스는 스폰 요청을 받고 `delayMs`가 지나면 표시한다.
   실리안은 원작이 키 입력 즉시(스폰 1초 전)라 스폰 트리거로는 1초 늦다 — 정확히 맞추려면
   캐스터 `ESTHER_CAST` 스냅샷에 에스더 슬롯을 실어 트리거를 옮기는 프로토콜 확장이 필요(후속 판단).
10. **Character Select 로더** — 발탄 로더와 같은 에스더 3종 NPC 프로토타입 prewarm 블록 추가
    (`CNpcPresentationAssetService::Begin_LevelLoad` 포함). 첫 발동 시 메인 스레드 모델 지연 로드 멈춤 제거.

## 검증

- `python -c json.load`로 JSON 3종 parse. `git diff --check`.
- 빌드: 사용자 요청 시(no-build 규칙).
- 실행(사용자): Valtan 진입 → 에스더 게이지 충전 → Ctrl+Z/X/C → 풀스크린 컷인 무비 1회 재생 후
  자동 소멸, 게이지 UI/HUD 위에 그려짐. F1 Debug 미리보기 버튼으로 재생. 시각 판정은 사용자 전용.
- VRAM 참고: 프레임은 `CUITextureCache`에 최초 재생 시 스트리밍 로드되고 상주한다
  (RaidEntry와 동일). 발탄 3종 전부 한 번 이상 재생 시 ≈306MB 상주.
