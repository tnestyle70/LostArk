# 2026-09-10 쿠크세이튼 입장 로딩 화면 RESULT

브랜치 `feature/kouku-loading-screen` (origin/main 기준).

쿠크세이튼 아레나로 넘어갈 때 로딩 화면의 배경과 제목을 그 레이드 것으로 바꾼다.

## 1. 제목과 팁 — 원작 테이블 실측

| 항목 | 값 | 출처 |
|---|---|---|
| 제목 | 한밤중의 서커스 | `EFTable_GameMsg` `sys.commander.dungeon_name_koukusaton` |
| 팁 | 한밤중의 서커스는 당신을 진심으로 환영합니다. | `sys.hint.zone_commanderraid_011` |
| 라벨 | 시나리오 | 기존 기본값 그대로 |

사용자가 첨부한 실제 게임 로딩 화면 캡처와 세 줄 모두 글자 단위로 일치한다.
맵 ID `LV_LUT_MIDNIGHTC_ED`(midnight circus)와도 맞는다.

발탄이 존 이름(`부활한 마수의 심장`)과 그 존을 지목하는 힌트 `_001`을 쓰는 것과 같은 자리다.
쿠크 힌트는 `_011~_014` 네 개이며 그중 존 이름을 담은 `_011`을 골랐다.

```
011  한밤중의 서커스는 당신을 진심으로 환영합니다.        <- 채택
012  어둠 속에서 악의로 가득한 웃음소리가 메아리칩니다.
013  장난과 속임수로 가득한 곳에서 쿠크세이튼이 당신을 기다리고 있습니다.
014  광기에 지배되지 않도록 주의하세요. 당신이 어떻게 변해버릴지 알 수 없습니다.
```

## 2. 배경

`Client/Bin/Resources/UI/Loading/Loading_Background_Kouku.png` 1280x720.

원본은 `EFUI_BACKGROUNDIMG`의 `lv_lut_commander_koukusaton_special`(604x704)이다. 이름부터
쿠크 전용이고 알파가 전면 불투명한 사각 스플래시라 오려내 다른 배경에 얹을 수 없다. 가로
1280에 맞춰 확대한 뒤 세로 중앙 띠를 잘라 16:9로 만들었다. 블러 확장이나 합성은 쓰지 않았다.

**이것은 원작 로딩 아트가 아니라 같은 게임 데이터에서 고른 대체본이다.**
기존 `Loading_Background_Valtan.png`도 같은 성격이다 — 대조해 보니 그 파일은
`EFUI_BACKGROUNDIMG`의 `raid_img_05`와 거리 11로 사실상 동일하다. 즉 발탄 것도 원작 발탄
로딩 아트가 아니라 이 패키지에서 집어 온 대체본이었다.

## 3. 진짜 원작 로딩 아트의 위치 — 찾았으나 못 뽑았다

정본 사슬은 확정했다.

```
EFTable_HintGroup           37081 -> sys.hint.zone_commanderraid_011~014
EFTable_LoadingImageGroup   37081 -> LoadingImage = COMMANDERRAID_03
```

그 이름의 파일이 `.upk` 밖에 따로 있다.

```
ReleasePC/Packages/ExtRes/Loading/{ZONE,GUIDE,EVENT}   633 / 117 / 9 개
    ZONE/AM88WFHO77WGH0FYJDEI6V.ipk = COMMANDERRAID_03   (쿠크, 5.59MB)
    ZONE/AM88WFHO77WGH0FY5DEI6V.ipk = COMMANDERRAID_01   (발탄)
    _02 비아키스 / _04 아브렐슈드 도 같은 폴더
```

파일명은 `Tools/MoviePipeline/deobfuscate_names.py`로 복원했다. 이 스크립트는 movie뿐 아니라
`.upk`와 `ExtRes`에도 그대로 동작하며, 33,908개 패키지 이름을 몇 초에 푼다.

복호화는 실패했다. Bink이 아니어서 `ipk_to_bk2` / `bink_key_solver` / `gallery.py`의 수렴
루프가 KB2·BIK 매직 9종 모두에서 발산하고, DDS 헤더 가정도 폭이 16억으로 나온다. 확인된
사실은 파일 두 개를 XOR하면 **주기 16**으로 반복된다는 것이다 — 헤더 평문이 모든 파일에서
동일하고 키가 16주기로만 다르다는 뜻이라, 하나만 풀면 633개가 전부 풀린다. 검증된 crib을
찾지 못했다.

가장 빠른 다음 수단은 알려진 평문 확보다. 게임이 복호본을 어딘가(`EFGame/CachedImage` 등)에
쓰게 만든 뒤 암호본과 XOR하면 키가 바로 나온다.

## 4. 구현

`Client/Private/Level_Loading.cpp` 두 곳만 손봤다. 레이아웃 문서를 새로 만들지 않고 발탄·
프롤로그가 쓰던 분기를 그대로 늘렸다.

- 목적 Level이 `KAKULSAYDON_ARENA`일 때 `m_strTitleText` / `m_strTipText` 설정.
  한글은 파일의 기존 관례대로 wide hex escape로 쓴다(이 파일은 BOM 없는 CP949 해석 대상이다).
- 같은 조건에서 `Background` 슬롯 텍스처를 `UI/Loading/Loading_Background_Kouku.png`로 교체.

`MainApp.cpp`의 로딩 배경 텍스처 프로토타입 등록 목록에도 같은 경로를 추가한다. 이 배경들은
`LoadingLayout.json`의 layers에 안 나타나서 자동 스캔이 못 찾고, 등록이 빠지면
`CUI_Sprite` clone이 텍스처 프로토타입을 못 찾아 `Ready_Prototype`이 `E_FAIL`을 돌려준다.
처음에 이 등록을 빠뜨려 로비에서 쿠크 진입 시 Failed가 났다. 발탄·프롤로그와 같은 배열이다.

리소스는 Git 비추적이며 팀장 Drive의 `Resources/UI` 폴더 통째 업로드에 포함된다.
