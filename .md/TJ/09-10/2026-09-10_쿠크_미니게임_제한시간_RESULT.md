# 2026-09-10 쿠크 미니게임 제한시간 표시 RESULT

브랜치 `feature/fear-status-text` (공포 문구 커밋에 이어서).

카드미로·마리오 구간에서 화면 좌상단에 뜨는 쿠크 전용 제한시간 위젯을 표현으로 만든다.

## 1. 실측한 원작 데이터

### 1.1 소유 위젯

| 항목 | 값 |
|---|---|
| 패키지 | `EFUI_DUNGEONTIMER` = `OVSG0AHSF2OMFLG8O7DR2Y.upk` |
| movie | `dungeontimer.gfx` |
| 클래스 | `ark.ui.dungeonTimer.DungeonTimerFrame` |
| 구성 | `raidImageMc`(문양) `timeTF`(숫자) `underBigTF`/`underSmallTF`(경고 구간) `warningEffect` `checkBG` `timerOverMc` `tickTimer` `setting` |

클래스에 레이드별 상수가 그대로 있다. `NONE 0 / KOUKUSATON 1 / COMMON 2 / ILLIAKAN 3 /
MOCOCONG 4 / ECHIDNA 5 / KAZEROTH 6`이며 `raidImageMc.gotoAndStop(type + 1)`이므로

일곱 요소 전부 같은 프레임 스프라이트(129)의 형제라 배치좌표는 문양 원점 기준이다.

연습모드 좌표 `(27, 9)` → `(18, 6)`은 모드를 나눌 때 쓸 값으로 남겨 둔다.

**색은 숨겨진 `setting` 클립의 텍스트필드에서 읽는다.** `configUI()`가 자식 `a`/`b`/`disableTF`의
`text`를 `uint`로 파싱한다.

- `b` = 정상 = **`0xFFD200`**
- `a` = 경고 = **`0xCC3300`**
- 비활성 = `0x787878` (클래스 기본값, `disableTF` 실값은 확인 못 함)

클래스 기본값 `0xFFD700`은 `setting`이 `0xFFD200`으로 덮는다.

### 1.3 동작

포맷은 `TranslateTime.getTime({timeType: "min"})`이고 분·초 모두 2자리 0채움,
구분자는 공백 없는 `":"`다. 스크린샷의 `02:27`과 일치한다.

`warningTime` 기본 10초. 그 아래로 내려가면 `timeTF`를 숨기고
`underBigTF = value.toString().substr(0,2)`, `underSmallTF = substr(2,3)`으로 갈라
초·소수 두 자리 표시가 된다. 동시에 밑 텍스트 색이 경고색으로 바뀌고
`warningEffect`/`checkBG`가 `gotoAndStop(type + 1)`로 레이드별 프레임이 된다.

그 밖에 `bIncreaseType`(증가/감소), `limitTime` 도달 시 `disableColor` + `setLimitText()`,
조건 `NONE(-1)/START(0)/END(1)/CANCEL(2)`, 종료 시 `timerOverMc` +
`nativeCallbackDungeonTimerTheEnd`가 있다.

## 3. 구현하지 않은 것

- **Server 계약이 없다.** 카드미로·마리오 어디에도 제한시간 필드가 없다
  (`CARD_MAZE_PRESENTATION`은 행진·전송 시계만, 상수는 `KOUKU_MAZE_HAMMER_COOLDOWN_MS`뿐).
  제한시간을 실제로 도입하려면 만료 시 무엇이 일어나는지가 gameplay 결정이라 이번 범위 밖이다.
  지금은 F1 프리뷰가 유일한 producer이며, 광기 게이지 Phase A와 같은 단계다.
  protocol은 78 그대로이고 Server 재빌드가 필요 없다.
- `warningEffect`, `checkBG`의 쿠크 프레임(char 22 / 36)은 단일 크롭이 아니라 중첩 애니메이션
  스프라이트라 이번에 넣지 않았다. 경고 구간의 색 전환과 초·소수 표시만 반영했다.
- `timeBG`는 `titleImageType == COMMON`일 때만 보이는 슬롯이라 쿠크 경로에서는 쓰지 않는다.

### 4.1 화면 확인에서 잡아 고친 것

| 증상 | 원인 | 수정 |
|---|---|---|
| 크기가 25% 작음 | 스테이지가 1920x1080인데 0.5배로 추측해 넣음 | 1280/1920 비율로 실측 적용 |
| 위치가 어긋남 | 눈대중으로 넣음 | 메인 타임라인 `widgetX/widgetY` 적용 |
| 숫자 크기가 들쭉날쭉 | 스케일을 그리는 문자열의 실측 높이로 나눔 (`10:00`과 `9.87`이 다름) | 고정 문자열 `"00:00"` 기준으로 변경 |
| 숫자가 빨간색 + 초·소수 분할 | `Run`이 `isVisible`만 켜고 `fSeconds`를 안 채워 0으로 남음 → 경고 분기 | `Run`이 정지·0일 때 시작값을 채우도록 |
| 숫자가 오른쪽·아래로 2px 밀림 | 필드 bounds `(-2,-2)`를 빼먹고 중심을 냄 | 세 필드 중심을 bounds 기준으로 재계산 |
| `size_t` 컴파일 오류 2건 | `(std::min)<size_t>(...)` — 괄호로 감싸면 템플릿 인자를 붙일 수 없다 | `substr`이 count를 자르므로 `min` 제거 |

## 5. 사용자가 확인할 경로

1. Client 빌드 후 쿠크세이튼 아레나 진입.
2. F1 → `Arena Camera / Player` → `Kouku UI Preview (Debug)` → `Dungeon timer (Debug)`.
3. `Show timer` 체크 후 `Run`. **게임 화면** 좌상단에 문양과 금색(`0xFFD200`) `MM:SS`가
   뜨고 기본 10:00에서 1초씩 줄어야 한다.
4. `Warn s`(기본 10) 이하로 내려가면 숫자가 초·소수 두 자리로 갈라지고 `0xCC3300`이 된다.
5. 위치·크기는 F1 → `HUD Layout Tool` → `Kouku Timer` 탭에서 문양을 끌어 옮기고 Save한다.
   숫자는 슬롯 width에서 파생되므로 같이 따라간다.

저장 대상은 `Data/UI/KoukuSaydon/DungeonTimer_Layout.json`이다.
