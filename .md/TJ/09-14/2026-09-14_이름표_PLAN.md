# 캐릭터 머리 위 이름표(head status) 원작 재구성 계획 (2026-09-14)

브랜치 `feature/nameplate` (origin/main, 탈것·전투분석기 머지 이후). 사용자 요청: "캐릭터 머리 위에 닉네임 뜨는 것 원작대로".

## 1. 현재 구현

`CWorldPlayerNameplateView::Render` — 캐릭터 위치 +2.2m를 화면에 투영해 `Font_YG330` 0.75배 흰색으로 닉네임만 중앙 정렬. 베른·발탄 레벨 `Render()`에서 호출, 캐릭터 선택·쿠크 레벨은 호출하지 않는다. 말풍선(`CWorldPlayerChatBubbleView`)은 +2.7m에 따로 그린다.

## 3. 구현

1. `Data/UI/HeadStatus/HeadStatus_Layout.json` (생성 스크립트 `Tools/LpkPipeline/build_head_status_ui.py`): 플레이어 8명분 `HS_{i}_HpFrame`(82×9)·`HS_{i}_HpFill`(78×5) slot, 아트 `UI/HeadStatus/*.png`(위 8 영역 크롭). 위치는 런타임이 매 프레임 `Set_SlotPosition`으로 옮긴다(파티 창의 HP fill과 같은 `Set_SlotFillRatio`).
2. `CWorldPlayerNameplateView`에 `Initialize(pDevice, pContext, iOwnerLevelIndex)` 추가 → 레벨 소유 `CUILayoutRuntime`(파티 초대 팝업과 같은 방식, 레벨 `Layer_UI`). `Render(players, roster, health)`로 시그니처 확장: 관계 = 본인(Player) / 파티(Party) / 그 외(Friend). 텍스트는 `Font_YG760` 12pt × 뷰포트 배율(`UILabelFont::Resolve`), `#ECECEC`, 그림자.
3. 배치: 머리 앵커 = 캐릭터 위치 + 2.2m(현행) → 화면 좌표. retail px는 1920 기준이므로 ×(뷰포트 높이/1080)로 환산. HP 프레임 (−39,−8), 이름 (0,−37) 중앙.
4. 베른·발탄 `Initialize`/`Render` 호출부에 device·roster·health 전달. 말풍선 오프셋은 스택 높이만큼 위로(2.7 → 3.0m 검토).
5. 말풍선: `HeadStatus_Balloon` normalBG 9-slice, `$YG760` 12px `#EEEEEE`, 폭 200, 15자 이하 중앙, 꼬리 13, 이름판 위에 스택.
6. 칭호(사용자 추가 결정): `Data/Titles/HonorTitles.json`(원작 완성형 17 + 프로젝트 6) → Server bootstrap admission, `PLAYER_SNAPSHOT.iHonorTitleId`(protocol 86), P창 「칭호변경」 → `honortitle.gfx` 축소 창(완성형 목록·현재 칭호·적용/해제) → 이름 앞 같은 줄. 원작 조사: `EFTable_HonorTitle` 821행(Type 0/1/2 = 238/232/351, Hidden 308), 이름 `tip.name.honortitle_<pk>`, 창 `honorTitleWnd` DefaultUIWindow_V2 (820,181.9) 452×800, 행 `HonorTitleRendererItem_big` 395×32, 배지 `honortitle_i7` (937,51) 60×30.
7. 제외: 길드, functional(자리비움 등), 방어막 트랙, 캐릭터 선택 레벨(닉네임 전).

## 4. 사용자 결정 필요

- 머리 위 HP바: 원작 `PcHeadStatusMc`에는 항상 들어 있고 표시 여부는 host 옵션. **본인 포함 전원 / 파티원만 / 없음** 중 선택.
- 칭호: 사용자 결정으로 이번에 포함(위 3.6). 길드는 생략.
