# 팀 테스트 UI 버그 2차 (2026-09-19)

브랜치 `feature/ui-bugbatch2-0919` (main 8dc16688 기준). 1차 배치(#413) 이후 제보된 8건.

## 1. 텍스트가 창 위로 뚫고 나오는 문제 — 근본 수정

### 원인
- `CGameInstance::Render()`는 `CRenderer::Draw()`(모든 UI 스프라이트, `RENDERGROUP::UI`) 다음에
  Level `Render()`(이름표·말풍선·레벨 팝업 텍스트)를 부르고, `CMainApp::Render()`의 UIText 단계가 그 뒤에
  나머지 텍스트를 그린다. 즉 **모든 텍스트가 모든 UI 스프라이트보다 나중에** 그려져, 어느 창의 글씨든
  다른 창 위로 올라온다.
- 그동안은 창마다 clip-out 사각형을 손으로 추가(`Add_OpenWindowTextClipOuts`, `Set_TopWindowRect`,
  창 목록 `ClipAbove`)해 때웠고, 새 창·팝업이 생길 때마다 뚫림이 재발했다.
- 1차 배치에서 팝업 자기 영역을 clip-out에 넣은 탓에 그 팝업 **자기 텍스트까지 지워졌다**
  (던전 진행 창, 파티초대 패널, 수락/거절 창 텍스트 누락 = 제보 5·6번).

### 수정: `CUITextOcclusion` (UI 텍스트 층 레지스트리)
- `Client/Public|Private/UITextOcclusion.*` (필터 `02.GameObjects\04. UI`).
- 층: `WORLD 0` < `HUD 100` < `WINDOW 200(+창 순번)` < `MODAL 300` < `PAGE 400`.
- 매 프레임 `Begin_Frame()`(입력 라우터와 같은 시점)에서 비우고, 보이는 UI 표면이 자기 화면 영역과 층을
  `Add_Occluder`/`Add_SlotOccluder`로 등록한다.
- 텍스트는 `CUITextLayerScope(층)` 안에서 그린다. 그 층보다 **높은** 층의 영역만 clip-out으로 적용되므로
  자기 창 글씨는 자기 창에 지워지지 않고, 위에 덮은 창 영역에서만 가려진다.
- 스코프 밖 텍스트는 `WORLD`로 취급(이름표·말풍선·데미지 숫자). 레벨 Render 직전에 `Apply(WORLD)`.
  층을 선언하지 않은 텍스트는 어떤 UI도 뚫지 못한다.
- 등록한 표면
  - WINDOW: 인벤토리(+0), 캐릭터정보(+1), 아바타도감(+2), 탈것(+3), 칭호(+4), 월드맵(+5), 환경설정(+6), 강화(+7)
  - HUD: 파티창(타이틀·행 심볼·HP바), 에스더 창, 관문 진행 위젯
  - MODAL: 파티 컨텍스트 메뉴·초대 팝업, 관문 진행/재시작 프롬프트, 베른 레이드 입장 창(전체 화면 딤),
    커스터마이징 화면(전체 화면)
  - PAGE: MVP 시상식(전체 화면)
- 텍스트 층: 전투 HUD·보스바·쿨다운·퀵슬롯·에스더·미니맵·채팅·파티창·데스/클리어 문구 = HUD,
  인벤토리·각 창·강화 = 각 WINDOW 순번, 모달류 = MODAL, MVP = PAGE, FPS = PAGE.
- 제거: `CUIInputRouter::Set_TopWindowRect`의 clip 설정, `ClipAbove` 창 루프, 1차의
  `Add_TextClipOuts()` 두 개(자기 텍스트를 지우던 원인).
