# 팀 테스트 UI 버그 배치 (2026-09-19)

브랜치 `feature/ui-bugbatch-0919` (main 911fd4af 기준). 팀 테스트에서 나온 UI 제보 13건.

## 항목별 원인과 수정

1. **이름표 가시성** — `WorldPlayerNameplateView`: 1px 그림자 하나뿐이라 밝은 바닥에서 묻혔다. 8방향 외곽선
   (검정 90%, 1080p 이상은 2px)으로 교체. 색·크기·배치는 그대로.
2. **파티초대 컨텍스트 메뉴 닉네임 넘침** — `PartyInteractionView`: 높이 기준 스케일만 있어 긴 닉네임이 박스를
   벗어났다. 패널 폭(−12px)에 맞춰 축소. 초대 확인 팝업의 설명 줄도 같은 폭 제한.
3. **로딩창 파티 텍스트** — `MainApp`: 파티창 스프라이트는 Bern/Valtan에서만 그리는데 `RenderText`는 레벨
   게이트가 없었다. Bern/Valtan/Kouku에서만 텍스트를 그린다.
4. **관문 진행 위젯과 에스더 창 겹침** — `Data/UI/Esther/EstherUI.json` 15개 슬롯 y +391 (프레임 (−4.5,49) →
   (−4.5,440)). 관문 위젯(32..147)·파티창(240..430) 아래, 퀵슬롯 위. 파일 형식은 그대로 두고 y 숫자만 바꿨다.
5. **닉네임이 창 위로 올라옴** — 텍스트 클립아웃 목록에 시상식·파티 팝업·관문 프롬프트가 없었다.
   - `CPartyInteractionView::Add_TextClipOuts()` (컨텍스트 메뉴 패널, 초대 패널),
     `CRaidGateProgressView::Add_TextClipOuts()` (프롬프트 패널)를 각 Level Render에서 이름표 렌더 직전에 호출.
   - 시상식 페이지가 열려 있으면 Valtan/Kouku Level이 이름표·말풍선 렌더 자체를 건너뛴다.
6. **강화창 ESC** — `MainApp::Update_SystemOptionWindow`의 ESC edge에서 강화 미리보기가 열려 있으면 닫는다.
   `Is_AnyRuntimeWindowOpen()`에 포함해 ESC가 환경설정을 열지 않는다.
7. **시상식 ESC → 환경설정이 뒤에 열림** — 같은 ESC edge에서 시상식이 열려 있으면 먼저 닫는다
   (`Level_ValtanArena::Hide_MvpResult()` 추가, Kouku는 기존 `Debug_Hide_MvpResult()`). 열린 창 목록에도 포함.
8. **캐릭터정보창 외형 미반영** — 캐릭터 선택에서 커스터마이징 화면이 열려 있을 때 정보창이 아레나의 복제
   캐릭터를 받고 있었다. 커스터마이징 미리보기 캐릭터(`m_pActiveCharacter`)를 주는
   `CLevel_CharacterSelect::Get_CharacterInfoCharacter()`로 교체. 초상 렌더러는 같은 캐릭터를 매 프레임 그리므로
   의상·머리 변경이 바로 보인다.
9. **칭호창 "그/크" 글리프** — 폰트 데이터 재검증: 원본 `YG760.spritefont`와 굽기 변형 `YG760_10..28` 모두
   글리프 rect/offset이 TTF 래스터와 일치한다(09-14 RESULT 기록과 같음). 즉 YG760(윤고딕 760 탈네모꼴)의
   글자 디자인이 짧은 음절을 기준선 위에 띄운다. 목록에서 오류처럼 보이므로 칭호 목록 행과 「사용중」 배지를
   `Font_YoonGasiIIM`으로 바꿨다(다른 창 본문과 같은 폰트).
10. **파티원 광기 게이지** — 파티 로스터 메시지에는 광기가 없지만 `SNAPSHOT_PLAYER`에는 모든 플레이어의
    `iCurrentMadness/iMaximumMadness`가 있다. `REPLICATED_PLAYER_HEALTH`에 광기 두 필드 추가(`Apply_Snapshot`),
    `PARTY_MEMBER`에 비율·유무, 파티창 행마다 HP 바 아래 얇은 보라 바(`PartyWindow_MadnessBg/Fill_0..3`,
    기존 HP 아트에 tint, 레이아웃 JSON에 추가만). 최대치 0인 월드(Bern/Valtan)에서는 숨김.
    파티창을 Kouku 아레나에서도 그리도록 `MainApp` 분기와 `Level_KakulSaydonArena` 로스터/HP 접근자 추가.
    protocol 변경 없음.
11. **파티원 우클릭 초대 패널** — `Update_ContextMenuTrigger`에 로스터를 넘겨 이미 파티원인 대상은 우클릭
    대상에서 제외.
12. **쿠크 에스더 게이지** — Server `CEstherSkillSystem::Initialize`가 Valtan/캐릭터선택만 켰다. `KAKULSAYDON_ARENA`
    추가. Client Loader가 쿠크 아레나에서도 에스더 소환수 3종 프로토타입을 준비(Valtan과 같은 목록).
    HUD 게이팅은 이미 Kouku를 허용하고 있었다. protocol 변경 없음, Server 재시작 필요.
13. **트리거박스 G 키캡** — 새 `CInteractKeyPromptView`(`Client/Public|Private/InteractKeyPromptView.*`,
    필터 `02.GameObjects\04. UI`): 아레나의 `Client/Bin/DataFiles/World/<Area>.viewer.world.json`에서
    `requiresInteract` 트리거박스 위치를 읽고, 로컬 플레이어 10m 안의 가장 가까운 박스 위(+1.2m)에 원작 키캡을
    투영해 띄운다. 아트는 `EFUI_SHAREIMAGE` `Shared_GlobalInputDeviceKey_G`(shareiconimage 이미지 6,
    (990,580) 34×35) → `UI/Interact/Key_G.png`, 레이아웃 `Data/UI/Interact/InteractKey_Layout.json`.
    Kouku Level에 연결(시상식 중 숨김). 현재 `requiresInteract` 박스는 쿠크 `Mario4_Tigger_2/3` 두 개이고
    발탄에는 없다. MapTool에서 박스에 requiresInteract를 켜면 자동으로 표시된다.
