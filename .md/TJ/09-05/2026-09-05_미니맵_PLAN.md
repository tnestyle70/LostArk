## 구현

- 리소스(`Client/Bin/Resources/UI/Minimap/` 전용): 틀·버튼 13장, 마커 3장, `Maps/<Level>.png` 3장.
  생성 스크립트 job tmp `minimap_assets.py`.
- 데이터: `Data/UI/Minimap/Minimap_Layout.json`(슬롯 21개), `MinimapAreas.json`(레벨별 이미지·cm 범위).
- 렌더: `Shader_VtxTex.hlsl` UI pass에 `g_UVOffset/g_UVScale`(텍스처 창) 추가,
  `CUI_Sprite::Set_UVWindow`, `CUILayoutRuntime::Set_SlotUVWindow`. 기본값은 기존 동작과 동일.
  Engine 공용 헤더는 손대지 않음. 원형 마스크는 사용자 결정으로 제거(원작의 원은 참고일 뿐).
- 데이터 소스: `CClientReplication::Collect_MinimapMarkers` (로컬 위치·yaw, 다른 플레이어+파티 여부,
  BOSS kind 엔티티 위치). Bern/Valtan/KakulSaydon 레벨이 `Get_PartyRoster`처럼 forwarding.
- 뷰: `CMinimapView`(신규, vcxproj/filters 등록, HUDLayoutTool 문서 "Minimap" 등록). 줌 5단계
  (뷰 가로 45/70/100/145/210m, 기본 100m), 플레이어 중앙 고정, 화살표는 character yaw − 90°
  (yaw 0 = +Z = 화면 왼쪽, yaw 90 = +X = 화면 위), 사각 뷰 밖 마커 숨김. `CMainApp::Update_Minimap/RenderMinimapText`가 활성 레벨에서 구동.
