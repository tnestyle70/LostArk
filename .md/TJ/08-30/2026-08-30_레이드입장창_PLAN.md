# 발탄 레이드 입장창 — 실제 스크린샷 기반 시각 클론 (1단계: 시각, 기능은 이후)

## 배경 / 요청

사용자가 실제 로스트아크 "군단장 레이드 입장" 창(쿠크세이튼 예시) 스크린샷을 첨부하고, 지금 Bern에서
쓰고 있는 단순 수락/거절 모달을 이 스타일로 바꾸고 싶다고 요청. 확정된 범위:

1. "일단 시각적으로 패널은 아예 똑같게 만들고 그다음 기능을 생각하자" — **이번 PLAN은 시각 클론만.**
   난이도별 아이템레벨 매칭, 실제 보상 산출, 매칭/파티찾기 시스템은 범위 밖.
2. 스크린샷의 보스(쿠크세이튼)는 이 프로젝트에 없는 보스이므로, **레이아웃/크롬만 그대로 가져오고
   실제 표시 내용은 발탄 것을 쓴다.**

## 실제 확인한 사실 (이번 세션에 직접 추출/검증, 추측 없음)

### 소스 자산 식별
- 패키지: `OVSG0AOTGA7WGHOFL7WFAO.upk`, 내부 `efswfmovie` 이름 `epicraidentrance`.
- umodel_lostark_v7으로 nameresolve, umodel_lostark_custom(`-game=loakr`)로 `epicraidentrance.gfx`
  실제 추출(761,598 bytes). `ffdec-cli -swf2xml`로 전체 구조 XML, `-export script`로 실제 AS3
  329개 클래스 전부 확보. **스크린샷에 보이는 모든 UI 요소 이름이 실제 AS3/PlaceObject 심볼명과
  전부 일치함을 확인** (아래 좌표표의 이름들이 그 증거).
- SWF `displayRect`가 `Xmax=38400 Ymax=21600` (twips) = **1920×1080** — 즉 아래 좌표는 전부
  1920×1080 캔버스 기준 실좌표이고, 창 전체가 거의 풀스크린을 덮는 스크린샷과 일치한다.

### 발탄 자체 2D 아트 부재 확인
`Client/Bin/Resources/UI` 전체를 `valtan`/`boss`/`raid` 키워드로 검색한 결과, 발탄 클로즈업
인물화/스플래시 아트는 **존재하지 않는다**. 유일한 후보 `UI/Loading/Loading_Background_Valtan.png`
(1188×656)는 발탄 아레나를 위에서 내려다본 전경 배경이지 인물 클로즈업이 아니다 — 실제 화면의
"보스 인물화" 슬롯 용도로 맞지 않는다.
**결정**: 이번 PLAN에서는 이 전경 이미지를 어둡게/블러 처리해 보스 인물화 자리의 **자리표시자
배경**으로 쓴다. 진짜 발탄 클로즈업 아트가 필요하면 별도 umodel 탐색(내부 심볼명 불명, 과거
EFUI_STATUS 프레임 탐색 때 90회 이상 실패한 전례 있음 — 키워드 추측 대신 GUI 브라우징이 필요)이
추가로 필요하며, 이는 이번 범위 밖으로 명시적으로 미룬다.

## 이번 PLAN의 명시적 범위

### 포함 (시각 클론)
- 패널 전체 배경: `I6` 상단 프레임 조각 + `I245` 비네트 페이드로 새 큰 패널(1920×1080 기준
  풀스크린 오버레이, 실제 스크린샷 비율)을 구성.
- 좌측 정보 스택: 적응 단계 텍스트, 골드 아이콘, 입장 가능 시간 텍스트 — **모코코 아이콘, 캐시샵
  버튼은 제외**(이 프로젝트에 해당 시스템 없음).
- 상단 난이도 탭: 노말/하드 2탭을 정적 이미지로 배치, 기본 "노말" 활성 상태만 그림. 클릭 전환 없음.
- 중앙: 발탄 이름 텍스트, 설명 텍스트, 보스 인물화 자리(위 "자리표시자" 결정 적용).
- 우측: 입장 조건 리스트 패널(고정 3~4줄 정적 텍스트: 최소 인원, 아이템 레벨, 주간 입장 제한 등
  현재 프로젝트가 실제로 가진 조건만), 스크롤바는 정적 이미지로만(드래그 없음).
- 하단: 기대 보상 캐러셀(정적 아이템 아이콘 슬롯 6개 — 발탄 클리어 보상 6종 재사용), 관문/적응 표시.
- 하단 버튼: 매칭 시작/파티 찾기(시각만, 클릭 no-op), **입장하기(기존 `ValtanEntry_ConfirmButton`
  로직 그대로 재사용, 슬롯 ID만 변경)**, 거절(기존 `ValtanEntry_CancelButton` 로직 그대로 유지).

### 명시적 제외 (이번 PLAN에서 만들지 않음)
- 스크롤바 실제 드래그, 프리셋 콤보박스 드롭다운 동작, 툴팁 호버 패널.
- 캐시샵(`showBMBtn`), 모코코 아이콘 — 이 프로젝트엔 해당 시스템이 없음.
- 매칭/파티찾기 실제 로직 — 시각 배치만.
- 진짜 발탄 클로즈업 인물화 — 자리표시자 사용, 원본 아트 확보는 별도 작업.
- 난이도별 실제 아이템레벨 조건/입장 가능 여부 판정 — 지금처럼 서버가 이미 승인한 입장만 다룸.

## 구현 설계

### 1. 데이터
- 신규 `Data/UI/Bern/ValtanRaidEntry_Layout.json` — 기존 `BernValtanEntry_Layout.json`을 대체.
  `lostark.ui-layout` 스키마 그대로, `"resolution": {"width": 1920, "height": 1080}`(위 실좌표를
  변환 없이 그대로 사용 가능). 슬롯 목록은 위 "포함" 범위에 대응하는 실좌표 기반 rect로 구성
  (패널 배경 1장, 좌측 정보 텍스트 마커 3개, 난이도 탭 이미지 1장, 보스 인물화 자리 1장, 조건
  리스트 배경+텍스트 마커 4개, 보상 아이콘 슬롯 6개, 버튼 4개[매칭/파티찾기/입장하기/거절]).
- `Client/Bin/Resources/UI/Bern/`에 신규 크롭 이미지 추가: `RaidEntry_PanelFrame.png`(I6에서
  크롭), `RaidEntry_Vignette.png`(I245), `RaidEntry_DifficultyTab.png`(I1에서 크롭한 금장식
  조각 활용), 보스 인물화 자리는 `Loading_Background_Valtan.png`을 어둡게 처리한
  `RaidEntry_BossPlaceholder.png`로 별도 저장(원본 훼손 안 함).

### 2. Client
- `Level_Bern.h`: `m_pValtanEntryView`의 JSON 경로만 신규 파일로 교체. 슬롯 ID 상수들
  (`ValtanEntry_ConfirmButton` 등)은 그대로 재사용해 `Render_ValtanEntryModal`/
  `Render_ValtanEntryModalText`의 기존 커맨드 전송 로직을 건드리지 않는다.
- `Level_Bern.cpp`의 `Render_ValtanEntryModal()`/`Render_ValtanEntryModalText()`: 새 슬롯들
  (좌측 정보 텍스트, 조건 리스트 텍스트, 보상 아이콘)을 그리는 코드를 추가하되, 기존 수락/거절
  버튼의 히트테스트·커맨드 전송 블록은 그대로 둔다(슬롯 rect만 새 좌표로 바뀜).
- 발탄 클리어 보상 6종 아이콘은 이미 `MEMORY`/이전 세션에서 확정된 `ITEM_UPGRADE_SLOTS`와 동일
  아이콘 경로를 재사용(신규 자산 불필요).

### 3. 검증
- `Data/UI/Bern/ValtanRaidEntry_Layout.json`의 JSON 유효성(parse) 확인.
- Debug 빌드: Client.
- 실행 검증(사용자 직접): Bern에서 발탄 입장 NPC 우클릭 → 새 큰 패널이 뜨는지, 레이아웃이
  스크린샷과 비율상 맞는지, 입장하기/거절 버튼이 기존과 동일하게 동작하는지 확인.

## 남은 미해결 사항 (이번 PLAN 이후 후속 결정 필요)
- 진짜 발탄 클로즈업 인물화 원본 확보 여부/방법.
- 매칭/파티찾기/난이도 전환의 실제 게임플레이 연동 여부와 범위.
- 입장 조건 리스트에 실제로 어떤 조건 문구를 넣을지(현재 프로젝트엔 아이템레벨 게이팅 자체가 없음 —
  문구만 시각적으로 채울지, 조건 시스템을 새로 만들지는 "그다음 기능을 생각하자"는 사용자 발언대로
  이후 별도 논의).
